# 课序 · AI 校园日程 MVP

这是“创新大赛 AI 日程”的首个可运行网页版本：把课程群通知变成可核对、可追踪、可排程的任务。

## 当前版本

- 中文响应式校园工作台
- 粘贴通知或导入 TXT
- 本地规则识别；可选服务端 AI
- 新增、改期、取消、完成均需人工确认
- 保存来源与原文证据，更新同一任务避免重复
- 固定事项避让与 14 天约束排程
- 浏览器本地保存、撤销、JSON 导出与恢复

网页使用预构建静态资源；完整开发源码与本地运行说明随项目版本提交。模型密钥只允许配置在 Cloudflare Worker Secrets，严禁提交到仓库。
